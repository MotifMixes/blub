# Save states and speed

The I Can Play Piano keeps nothing of its own between plays. Blub's save states keep the whole console where it is.

- **Emulation › Save State** and **Load State**: five slots per game. `F5` saves slot 1, `F9` loads it.
- Hold the key left of `1` to **rewind** up to 30 seconds.
- Hold `Tab` to **fast-forward**. **Emulation › Speed** sets 50% to 400% or unlimited.
- Right-click a game in the library › **Delete save states…** removes them (a copy goes to the backups folder).
