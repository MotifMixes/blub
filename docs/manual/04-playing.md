# Playing

## The piano's keys

The keys follow MAME's layout: three octaves on three rows of letters.

| Piano | PC keys |
|---|---|
| Low octave (F2 to E3) | `\` `A Z S X D C V G B H N` |
| Middle octave (F3 to E4) | `M K , L . ; Q W 3 E 4 R` |
| High octave (F4 to E5) | `T 6 Y 7 U 8 I O 0 P - [` |

The first key, `\`, is the key left of `Z` on keyboards that have one. Change any key in **Input › Key bindings…**.

## The buttons

| Button | Key | Controller |
|---|---|---|
| Enter | `Enter` | A |
| Home | `Home` or `Backspace` | B |
| Up / Down | `↑` / `↓` | D-pad, left stick |
| Change instrument | Number pad `5` | X |
| Hands | Number pad `6` | Y |
| Display 1 to 4 | Number pad `1` to `4` | |
| Tempo up / normal / down | Number pad `+` / `*` / `-` | RB / - / LB |
| Pause | Number pad `7` | Start |
| Metronome | Number pad `8` | |

What some buttons do in each game is not yet known for certain.

## The console view

`F7` (or **Video › Console view**) shows the picture on a TV above a drawing of the piano, made after the real one: its colour-coded keys, the panel's buttons and the hands' lights, which light up red for the hand a song is teaching. The drawn keys sit right under the keyboard the songs show on the TV. Click its keys and buttons to play them: hold the mouse button and slide along the keys to play one after another. Keys light up while they are held, from the PC keyboard, a MIDI keyboard or the mouse. **Show keys on the console** shows each one's PC key.

## Keyboard Mode

The real piano has a TV / Keyboard Mode slider. **Input › Keyboard Mode** moves it: in Keyboard Mode there is no TV picture and the keys simply play notes.
