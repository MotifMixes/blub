# When something goes wrong

## A cartridge won't open

I Can Play Piano cartridges are 8 MB. A file of another size is not one (or the dump is incomplete).

## No sound

Check **Audio › Mute** and the volume, and that the game isn't fast-forwarding (sound plays at normal speed only).

## The MIDI keyboard does nothing

Check **Input › MIDI input**: is it listed, and chosen (or Automatic)? Another program that has the keyboard open may keep Blub from opening it.

## Reporting a problem

Send the file `blub.log` with your report. It is in `%APPDATA%\Blub` on Windows (paste that into the File Explorer address bar) and `~/.config/blub` on macOS and Linux.
