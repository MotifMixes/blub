# MIDI keyboards

A MIDI keyboard (USB, or any MIDI input your computer has) plays the piano's keys.

1. Plug it in.
2. Start a game. Blub opens the first MIDI input it finds and says so at the top of the window.

A keyboard plugged in later is found within a few seconds. **Input › MIDI input** lists the inputs there are: choose one, **Automatic** (the first one) or **None**. Blub remembers the choice.

## Notes and octaves

The piano has three octaves, F2 to E5 (its middle C is middle C). Notes below or above them play nothing, so a bigger keyboard plays just as the piano does and no key surprises you. **Octave shift** in the same menu moves everything up or down by one or two octaves first.

"All notes off" from the keyboard lets go of everything.
