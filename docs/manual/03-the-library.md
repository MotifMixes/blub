# The game library

The library shows every I Can Play Piano cartridge in your games folders, with its title screen. Blub makes each picture once, by running the game unseen for a few seconds; right-click a game and choose **Get title screen again** to make it anew.

## Finding games

- **Add games folder** (or **File › Games Folders**) adds a folder; Blub looks three folders deep.
- The ⟳ button looks again (after you copy new games in).
- Cartridges are found by their size (8 MB), raw or in a `.zip`.

## Favourites and folders

- Click the star on a game (or right-click › **Add to favorites**) to put it on the **★ Favorites** page.
- Right-click › **New folder** makes a folder of games; drag games onto a folder to add them.

## The game's own settings

While a game runs, **Emulation › Custom settings for this game** keeps the picture, sound, speed and control settings you change for that game alone.
